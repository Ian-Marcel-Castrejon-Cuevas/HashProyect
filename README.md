# HashProyect
Este programa es una aplicación de escritorio en Java (Swing) que simula un sistema básico de gestión de cuentas bancarias.

Permite registrar, buscar y eliminar clientes del banco. Cuando se registra un cliente, el programa solicita el nombre y el saldo inicial, genera automáticamente un número de cuenta aleatorio y guarda la información utilizando estructuras de datos como Hashtable y ArrayList. Los datos de las cuentas se muestran en un área de texto dentro de la interfaz.

Además, el usuario puede buscar una cuenta específica ingresando su número para ver el nombre y saldo del cliente, o eliminar una cuenta del sistema.
